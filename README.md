# nvim-starter

## Steps

1. Install package manager lazy.nvim
2. Install colorscheme
3. Install neo-tree
4. Install mason
5. Add bin path to $PATH
6. install lua_ls and ts_ls
7. Copy config from nvim-lspconfig
8. Enable lua_ls/ts_ls
9. Install treesitter
10. Install snacks
11. Install easy-dotnet.nvim
1x. Instal nvim-dap

13. Test debugger
